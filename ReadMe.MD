My Fruit Worth:
The goal of this game is to pick all the fruits growing on your farm before nighfall (2 minutes). 

Users can move forward, backward, left or right by using arrow keys. 
Users can reset the game with the R key. 

3 different levels can be toggled via radio buttons to change the graphics behind objects drawn to the screen.

When a user is within a specific distance from a fruit object, they may pick it up by pressing the spacebar. The fruit will then be placed in their "basket". 
Once all the fruits have been collected by the player, a winning screen appears and functionality is disabled. 
The user may play again by pressing R.
